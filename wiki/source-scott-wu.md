# Source: Inside Devin: The AI engineer that's set to write 50% of its company's code this year | Scott Wu

## Executive summary

Scott Wu, co-founder and CEO of Cognition, explains how Devin — the world's first autonomous AI software engineer — works as a fully asynchronous agent that integrates into Slack, Linear, and GitHub to function like a junior engineer on your team. Cognition's 15-person engineering team already delegates roughly a quarter of its pull requests to Devin, with expectations to surpass 50% by year's end. Wu argues that reinforcement learning and the agentic paradigm shift are transforming software engineering from bricklaying to architecture, where humans define problems and Devin handles implementation. He shares the origin story from competitive-programming hackathon to eight pivots, emphasizes stickiness over moats, and contends that AI will create more engineers — not fewer — through Jevons Paradox, because the demand for software far exceeds current capacity.

## Key ideas

1. **Bricklayer to Architect**: Devin enables engineers to shift from spending 90% of their time on implementation (debugging Kubernetes errors, fixing bugs, migrations) to focusing on the 10% that matters most — defining problems, designing architecture, and specifying intent. Each engineer on Cognition's team works with up to five Devins simultaneously.
2. **Reinforcement Learning as the Next Paradigm**: Wu bet early that high-compute RL — where models learn from automated feedback loops (running and testing code) — would surpass imitation learning. Code was the ideal domain because it provides natural automated evaluation, and this conviction led them to build agentic coding from November 2023.
3. **Stickiness Over Moats**: Rather than hard barriers to entry, Wu argues the defensibility of AI coding agents comes from accumulated stickiness — Devin learns a team's codebase, processes, and conventions over time, and multiplayer collaboration (Slack threads, PR reviews, shared context) compounds its value across the entire organization.
4. **Jevons Paradox Applied to Software Engineering**: As programming becomes easier and more effective, total demand for software will grow even faster than productivity gains. Wu predicts there will be far more programmers in a few years, not fewer, because humanity consistently finds more things to build software for.
5. **AI Growth Without Hardware Constraints**: Unlike the PC, internet, and mobile revolutions that depended on physical hardware distribution, AI's growth has no weight on hardware distribution for end users, making the technology's adoption curve exponentially faster than any prior tech shift.

## Concepts & frameworks

- [[ai-agents|Autonomous AI Agent]] — An AI system that can independently make decisions, interact with real-world tools, iterate on work, and complete multi-step tasks end-to-end.
- **Jagged Intelligence** — The idea that AI agents have an uneven capability profile — superhuman at some tasks (code retrieval, token processing) while still junior-level at others.
- [[jevons-paradox-software|Jevons Paradox]] — As the cost/effort of producing something decreases, total consumption often increases rather than decreases, applied here to software engineering.
- [[post-training-data-moat|Reinforcement Learning (RL)]] — A training paradigm where models learn from task completion and automated evaluation rather than just imitating internet text.
- [[ai-agents|Asynchronous Agentic Workflow]] — A work pattern where engineers delegate tasks to multiple AI agents running in parallel, checking in only as needed to steer or review.
