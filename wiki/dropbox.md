# Dropbox

File sync and sharing product. Canonical early-growth case study for the double-sided referral loop that [[sean-ellis|Sean Ellis]] helped design.

## Referral loop

- Give the referrer **extra storage space** for successful invites.
- Give the new user **extra storage space** for signing up via referral.
- The reward was denominated in the product's own unit of value (storage), which made the loop cheap to run and perfectly aligned with activation.

This design became a template for PLG referral programs across SaaS.
