## Executive summary

Ethan Smith, CEO of Graphite SEO, maps the second-biggest shift in SEO history: from optimizing for Google's blue link to optimizing for LLM answers (AEO). The key difference—LLMs summarize many citations, not ranking one winner—so you need mentions across Reddit, YouTube, blogs, and your own site. Smith details the RAG (retrieval-augmented generation) side of LLMs, breaks AEO into five actionable steps (identifying questions, covering subtopics, citation research, Reddit strategy, community answers), and emphasizes that authentic community participation beats spammy bots because LLMs are trained to trust sources like Reddit that self-police content quality.

## Key ideas

1. AEO is the second-biggest SEO shift since Panda/Penguin (spam vs. non-spam); LLMs summarize many citations so you need to show up across multiple sources, not win one top link like Google.
2. Only the RAG (retrieval-augmented generation) layer is controllable—recent web search and citations; the core model training data is too slow to influence, so focus on getting cited everywhere post-training.
3. Reddit is heavily cited in LLMs because it's self-policing (real people, authentic opinions, community moderation); spam accounts get banned, so the win is being an actual user giving useful answers, not automating 100 fake accounts.
4. You need to answer ALL the subtopic questions in a topic to rank; the more follower questions you answer that competitors don't, the more LLMs will cite you over them in summaries.
5. Content strategy for AEO: find which questions people ask (search data + support tickets + Reddit), identify which subtopics you'll own, mine citations you want (your site, YouTube, Reddit, Dotdash tier, blogs), and execute specific strategies per citation type.

## Concepts & frameworks

- [[answer-engine-optimization|Answer Engine Optimization (AEO)]] — Optimizing to appear in LLM-generated answers (ChatGPT, Claude, Gemini, Perplexity) rather than Google links; requires citations across multiple sources since LLMs summarize rather than rank one winner.
- **RAG (Retrieval-Augmented Generation)** — Post-training layer where LLMs search recent web content and cite sources; this is the controllable layer for AEO, not the core model training data which is too slow to influence.
- **Topic Coverage for AEO** — Like SEO, AEO requires covering all subtopic questions; the more questions you answer that competitors don't, the more likely LLMs cite you in summaries rather than them.
- **Citation Tier Strategy** — Organize AEO efforts by citation source type (your site, YouTube, UGC, Quora, Reddit, Dotdash tier-one affiliates, blogs) and run specific tactics for each, e.g., authentic Reddit answers, not bots.
